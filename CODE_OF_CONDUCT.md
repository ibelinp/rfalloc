# Code of Conduct

## The short version

Be civil. Assume the other person is acting in good faith. Argue about the data,
not the person.

## Scope

This applies in issues, pull requests, discussions, and anywhere else someone is
representing the project.

## Unacceptable

Harassment, personal attacks, publishing anyone's private information, sustained
disruption, and sexualised language or imagery.

## Enforcement

Report a problem by opening a [security advisory](https://github.com/ibelinp/rfalloc/security/advisories/new),
which is private, or by contacting the maintainer through their GitHub profile.
Reports are handled confidentially. Maintainers may edit or remove content,
close threads, or block accounts.
